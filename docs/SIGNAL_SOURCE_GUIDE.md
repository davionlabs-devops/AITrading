# 信号源配置说明

## 🎯 什么是信号源？

**信号源**是AI交易系统用来**发现潜在交易机会**的数据源。系统会从这些信号源获取币种列表，然后AI分析这些币种，决定是否交易。

---

## 📡 两种信号源

### 1. Coin Pool 信号（币种池信号）

**作用**: 从外部API获取**评分较高的币种列表**

**数据来源**: 
- 外部API（需要配置 `coin_pool_url`）
- 如果未配置API，使用默认主流币种列表

**数据内容**:
```json
{
  "pair": "BTCUSDT",
  "score": 85.5,              // 评分（越高越好）
  "increase_percent": 5.2,     // 涨幅百分比
  "start_price": 95000,        // 开始价格
  "max_price": 98000,          // 最高价格
  "max_score": 90.0            // 最高评分
}
```

**工作原理**:
1. 系统定期从API获取币种池数据
2. 按评分排序，选择评分最高的币种
3. 这些币种会成为AI的"候选币种"
4. AI分析这些候选币种，决定是否开仓

**使用场景**:
- ✅ 发现热门币种
- ✅ 发现涨幅较大的币种
- ✅ 发现市场关注度高的币种

**配置位置**: 
- Web界面: `信号源配置` → `Coin Pool 信号`
- 交易员配置: 创建/编辑交易员时选择 `use_coin_pool: true`

---

### 2. OI Top 信号（持仓量Top信号）

**作用**: 从外部API获取**持仓量增长最快的币种**

**数据来源**: 
- 外部API（需要配置 `oi_top_url`）
- OI = Open Interest（持仓量/未平仓合约数）

**数据内容**:
```json
{
  "symbol": "BTCUSDT",
  "rank": 1,                   // OI Top排名
  "oi_delta_percent": 15.5,   // 持仓量变化百分比（1小时）
  "oi_delta_value": 1000000,   // 持仓量变化价值
  "price_delta_percent": 3.2,  // 价格变化百分比
  "net_long": 500000,          // 净多仓
  "net_short": 300000          // 净空仓
}
```

**工作原理**:
1. 系统定期从API获取OI Top数据
2. 选择持仓量增长最快的币种
3. 这些币种会成为AI的"候选币种"
4. AI分析这些候选币种，决定是否开仓

**使用场景**:
- ✅ 发现资金流入的币种（持仓量增长）
- ✅ 发现市场情绪变化的币种
- ✅ 发现潜在突破的币种

**配置位置**: 
- Web界面: `信号源配置` → `OI Top 信号`
- 交易员配置: 创建/编辑交易员时选择 `use_oi_top: true`

---

## 🔄 信号源如何工作？

### 完整流程：

```
1. 系统启动
   ↓
2. 检查信号源配置
   ├─ Coin Pool 信号启用？ → 从API获取币种池
   └─ OI Top 信号启用？ → 从API获取OI Top数据
   ↓
3. 合并币种列表
   ├─ 来自Coin Pool的币种（标记为 "ai500"）
   └─ 来自OI Top的币种（标记为 "oi_top"）
   ↓
4. 去重和排序
   ├─ 如果币种同时出现在两个信号源 → 标记为 "AI500+OI_Top双重信号"
   └─ 按评分/持仓量增长排序
   ↓
5. 传递给AI分析
   ├─ AI看到候选币种列表
   ├─ 每个币种都有市场数据（价格、技术指标等）
   └─ AI决定是否交易
```

### 在AI提示词中的显示：

```
## 候选币种 (15个)

### 1. BTCUSDT (AI500+OI_Top双重信号)

价格: 98000.00
1小时变化: +2.5%
4小时变化: +5.2%
MACD: 0.0123
RSI: 65.5
...

### 2. ETHUSDT (OI_Top持仓增长)

价格: 3500.00
...
```

## ⚙️ 如何配置信号源？

### 方法1: Web界面配置

1. **全局信号源配置**:
   - 进入 `信号源配置` 页面
   - 配置 `Coin Pool API URL`
   - 配置 `OI Top API URL`
   - 这些是全局配置，所有交易员都可以使用

2. **交易员级别配置**:
   - 创建/编辑交易员时
   - 勾选 `使用 Coin Pool 信号`
   - 勾选 `使用 OI Top 信号`
   - 每个交易员可以独立选择使用哪些信号源

### 方法2: 数据库配置

```sql
-- 配置用户信号源URL
INSERT INTO user_signal_sources (user_id, coin_pool_url, oi_top_url)
VALUES ('admin', 'https://your-api.com/coin-pool', 'https://your-api.com/oi-top');

-- 配置交易员使用信号源
UPDATE traders 
SET use_coin_pool = 1, use_oi_top = 1 
WHERE id = 'your_trader_id';
```

## 📊 信号源组合策略

### 策略1: 只使用 Coin Pool
- **配置**: `use_coin_pool: true`, `use_oi_top: false`
- **适用**: 关注热门币种和涨幅
- **优点**: 简单，数据源稳定
- **缺点**: 可能错过资金流入但涨幅不大的币种

### 策略2: 只使用 OI Top
- **配置**: `use_coin_pool: false`, `use_oi_top: true`
- **适用**: 关注资金流入和持仓量变化
- **优点**: 能发现潜在突破
- **缺点**: 可能错过已经涨幅很大的币种

### 策略3: 同时使用两个信号源（推荐）
- **配置**: `use_coin_pool: true`, `use_oi_top: true`
- **适用**: 全面覆盖，不遗漏机会
- **优点**: 
  - 双重信号更可靠（同时出现在两个信号源的币种）
  - 覆盖更多币种
  - AI可以综合判断
- **缺点**: 候选币种可能较多，AI分析时间稍长

## 🎯 实际使用示例

### 场景1: 发现热门币种

**配置**:
- Coin Pool: ✅ 启用
- OI Top: ❌ 禁用

**结果**:
- AI会分析评分高的币种（如涨幅大、关注度高）
- 适合追涨策略

### 场景2: 发现资金流入币种

**配置**:
- Coin Pool: ❌ 禁用
- OI Top: ✅ 启用

**结果**:
- AI会分析持仓量增长快的币种
- 适合捕捉突破机会

### 场景3: 全面覆盖（推荐）

**配置**:
- Coin Pool: ✅ 启用
- OI Top: ✅ 启用

**结果**:
- AI会分析所有候选币种
- 如果币种同时出现在两个信号源，会标记为"双重信号"
- 双重信号的币种通常更可靠

## ⚠️ 注意事项

### 1. API配置

- **必须配置API URL**: 如果不配置，系统会使用默认主流币种列表
- **API可用性**: 如果API不可用，系统会使用缓存数据或默认列表
- **API响应时间**: 建议API响应时间 < 5秒

### 2. 数据缓存

- 系统会自动缓存信号源数据
- 缓存位置: `coin_pool_cache/latest.json`
- 如果API失败，会使用缓存数据

### 3. 默认币种列表

如果信号源API不可用，系统会使用默认主流币种：
```
BTCUSDT, ETHUSDT, SOLUSDT, BNBUSDT, 
XRPUSDT, DOGEUSDT, ADAUSDT, HYPEUSDT
```

## 📝 总结

**信号源配置**是AI交易系统的"眼睛"，帮助系统发现潜在交易机会：

1. **Coin Pool信号**: 发现热门和涨幅大的币种
2. **OI Top信号**: 发现资金流入和持仓量增长的币种
3. **双重信号**: 同时出现在两个信号源的币种更可靠

**建议**: 同时启用两个信号源，让AI有更多选择，提高交易机会的发现率。
