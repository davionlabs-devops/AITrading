# APEX 前端自研策略使用指南

## 概述

APEX 前端自研策略（原置信度策略，Confidence Strategy）是基于多因子分析的智能交易策略，通过综合评估8个维度的信号强度来计算最终置信度，只有高置信度（≥75%）的交易机会才会被执行。

## 策略特点

### 1. 多因子验证系统

策略通过8个维度综合评估交易机会：

| 因子 | 权重 | 说明 |
|------|------|------|
| 技术指标因子 | 25% | RSI、MACD、布林带、移动平均线等 |
| 价格行为因子 | 20% | 价格变化、动量、支撑阻力位 |
| 资金流向因子 | 18% | A/D线、VWAP分析 |
| 动量因子 | 13% | 动量强度、UO确认 |
| 市场结构因子 | 12% | VWAP趋势、波动率结构 |
| 市场情绪因子 | 10% | 综合市场情绪 |
| 成交量因子 | 5% | 成交量分析、触底反弹检测 |
| 波动性因子 | 5% | 波动率分析 |

### 2. 触底反弹检测

策略具备智能触底反弹检测功能，能够识别：
- 超卖信号组合（RSI < 30, 技术指标得分 > 70）
- 成交量异常放大（> 平均成交量 × 1.5）
- 价格接近支撑位
- 连续下跌后的反弹机会
- 动量减弱信号

当检测到触底反弹信号时，置信度会大幅提升，并强制看涨方向。

### 3. 风险等级评估

策略自动评估风险等级：
- **Low**: 风险评分 < 2
- **Medium**: 风险评分 2-4
- **High**: 风险评分 ≥ 4

根据风险等级和置信度自动调整仓位：
- 置信度 > 80% + 风险 Low: 标准仓位 (100%)
- 置信度 75-80% + 风险 Low: 标准仓位 (100%)
- 置信度 75-80% + 风险 Medium: 减仓 (80%)
- 置信度 ≥ 75% + 风险 High: 减仓 (50%)
- 置信度 < 75%: 不开仓

## 使用方法

### 1. 创建交易员时选择策略

在 Web 界面创建新交易员时：
1. 填写交易员基本信息
2. 在"系统提示词模板"下拉菜单中选择 `confidence_strategy`（显示为：APEX 前端自研策略）
3. 保存并启动交易员

### 2. 编辑现有交易员

对于已存在的交易员：
1. 进入交易员详情页面
2. 点击"编辑"按钮
3. 修改"系统提示词模板"为 `confidence_strategy`（显示为：APEX 前端自研策略）
4. 保存更改
5. 重启交易员使新策略生效

## 决策输出格式

策略会输出包含详细置信度分解的决策：

```json
{
  "action": "open_long",
  "symbol": "BTCUSDT",
  "quantity": 0.001,
  "leverage": 5,
  "stop_loss": 102000,
  "take_profit": 105000,
  "confidence": 82,
  "confidence_breakdown": {
    "technical": 75,
    "money_flow": 68,
    "momentum": 72,
    "market_structure": 70,
    "price_action": 78,
    "market_sentiment": 65,
    "volume": 85,
    "volatility": 60
  },
  "risk_level": "low",
  "reasoning": "技术指标显示超卖反弹，成交量异常放大，价格接近支撑位，触底反弹信号强烈，置信度82%"
}
```

### 字段说明

- `confidence`: 最终综合置信度 (0-100)
- `confidence_breakdown`: 各因子得分详情
  - `technical`: 技术指标得分
  - `money_flow`: 资金流向得分
  - `momentum`: 动量得分
  - `market_structure`: 市场结构得分
  - `price_action`: 价格行为得分
  - `market_sentiment`: 市场情绪得分
  - `volume`: 成交量得分
  - `volatility`: 波动性得分
- `risk_level`: 风险等级 (low/medium/high)
- `reasoning`: 决策理由

## 开仓条件

策略只在满足以下**所有条件**时才开仓：

1. ✅ 最终置信度 ≥ 75%
2. ✅ 至少3个因子得分 > 60
3. ✅ 因子一致性 > 0.6
4. ✅ 风险等级 ≤ medium

## 平仓条件

满足以下任一条件时平仓：

1. 置信度降至 < 50%
2. 达到止损/止盈目标
3. 信号反转（看涨变看跌或反之）
4. 风险等级升至 high

## 策略优势

### 1. 高精度筛选

通过多因子验证，确保只有高质量的交易机会才会被执行，避免低质量信号导致的亏损。

### 2. 智能风险控制

根据市场条件和风险等级自动调整仓位，在保护资金的同时最大化收益。

### 3. 触底反弹识别

能够识别市场超卖后的反弹机会，在合适的时机入场。

### 4. 因子一致性检查

确保多个因子指向同一方向，避免信号矛盾导致的错误决策。

## 最佳实践

### 1. 耐心等待

策略设计为"大多数时候等待，只在极佳机会时交易"。不要期望每个周期都有交易。

### 2. 关注置信度分解

通过查看 `confidence_breakdown` 了解每个因子的贡献，有助于理解决策逻辑。

### 3. 监控风险等级

如果风险等级持续为 high，考虑暂停交易或降低仓位。

### 4. 历史反馈学习

策略会根据历史表现自动调整：
- 胜率 < 40%: 提高置信度阈值至 80%
- 胜率 > 60%: 可适当降低置信度阈值至 70%
- 连续亏损: 自动停止交易，观望至少6个周期

## 常见问题

### Q: 为什么策略很少交易？

A: 这是正常的。策略设计为只在置信度 ≥ 75% 时才交易，大多数时候市场条件不满足这个要求。这有助于避免低质量交易。

### Q: 如何提高交易频率？

A: 不建议强制提高交易频率。如果确实需要，可以：
1. 降低置信度阈值（不推荐，会增加风险）
2. 等待更好的市场条件
3. 使用其他更激进的策略模板

### Q: 置信度分解中的某个因子得分很低怎么办？

A: 这是正常的。只要最终综合置信度 ≥ 75% 且满足其他条件，就可以交易。但如果多个因子得分都很低，说明信号质量不高，应该等待。

### Q: 如何判断策略是否有效？

A: 关注以下指标：
- 交易胜率（应该 > 50%）
- 平均盈亏比（应该 > 1:2）
- 夏普比率（应该 > 0.5）
- 最大回撤（应该 < 20%）

## 技术细节

### 置信度计算公式

```
加权得分 = 
  技术指标得分 × 0.25 +
  资金流向得分 × 0.18 +
  动量得分 × 0.13 +
  市场结构得分 × 0.12 +
  价格行为得分 × 0.20 +
  市场情绪得分 × 0.10 +
  成交量得分 × 0.05 +
  波动性得分 × 0.05

市场条件调整:
- 高波动环境: 加权得分 × 0.9
- 低波动环境: 加权得分 × 1.05
- 趋势一致性: 加权得分 × 1.05

因子一致性调整:
一致性因子 = max(0, 1 - 标准差 / 50)
最终置信度 = 加权得分 × (0.8 + 一致性因子 × 0.2)

最终置信度 = max(60, min(95, 调整后的置信度))
```

### 触底反弹检测逻辑

当检测到以下信号时，触发触底反弹检测：
- 技术指标得分 > 70 (超卖)
- 成交量得分 > 70 (放量)
- 价格接近支撑位 (position < 0.3)
- 连续下跌 ≥ 3根
- 动量减弱 (momentum > -0.005 且 < 0.005)

触底反弹强度 = 所有信号得分之和 / 100
触底反弹置信度 = 基础置信度 + 触底反弹强度 × 50

如果触底反弹强度 ≥ 0.4 且信号数 ≥ 2:
- 最终置信度 = max(75, min(95, 触底反弹置信度))
- 强制看涨方向
