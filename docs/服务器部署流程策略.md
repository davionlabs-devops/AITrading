## 环境准备

### 1.1 服务器要求

**最低配置：**
- CPU: 2核心
- 内存: 4GB RAM
- 磁盘: 20GB 可用空间
- 网络: 稳定的互联网连接

**推荐配置：**
- CPU: 4核心或更多
- 内存: 8GB RAM 或更多
- 磁盘: 50GB+ SSD
- 网络: 100Mbps+ 带宽

### 1.2 操作系统

支持的操作系统：
- Ubuntu 20.04 LTS 或更高版本（推荐）
- Ubuntu 22.04 LTS
- Debian 11 或更高版本
- CentOS 7/8（需要额外配置）

### 1.3 系统更新

```bash
# Ubuntu/Debian
sudo apt update && sudo apt upgrade -y

# CentOS
sudo yum update -y
```

### 1.4 创建专用用户

```bash
# 创建 nofx 用户
sudo useradd -m -s /bin/bash nofx
sudo passwd nofx

# 添加到 sudo 组（可选）
sudo usermod -aG sudo nofx

# 切换到 nofx 用户
su - nofx
```

## 依赖安装

### 2.1 安装 Go 语言环境

```bash
# 下载 Go（版本 1.21 或更高）
cd /tmp
wget https://go.dev/dl/go1.21.5.linux-amd64.tar.gz

# 解压到 /usr/local
sudo tar -C /usr/local -xzf go1.21.5.linux-amd64.tar.gz

# 设置环境变量
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
echo 'export GOPATH=$HOME/go' >> ~/.bashrc
echo 'export GOROOT=/usr/local/go' >> ~/.bashrc
source ~/.bashrc

# 验证安装
go version
```

### 2.2 安装 Node.js 和 npm

```bash
# 使用 NodeSource 仓库安装 Node.js 20.x
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装
node --version
npm --version

# 安装 pnpm（推荐，更快）
npm install -g pnpm
```

### 2.3 安装 TA-Lib（技术分析库）

```bash
# 安装依赖
sudo apt-get install -y build-essential wget

# 下载 TA-Lib
cd /tmp
wget http://prdownloads.sourceforge.net/ta-lib/ta-lib-0.4.0-src.tar.gz
tar -xzf ta-lib-0.4.0-src.tar.gz
cd ta-lib/

# 编译安装
./configure --prefix=/usr
make
sudo make install

# 更新库路径
sudo ldconfig
```

### 2.4 安装其他系统依赖

```bash
# Ubuntu/Debian
sudo apt-get install -y \
    git \
    curl \
    wget \
    sqlite3 \
    supervisor \
    nginx \
    ufw \
    fail2ban
```

## 服务部署

### 4.1 编译后端服务

```bash
cd ~/projects/nofx-dev

# 编译 Go 程序
go mod download
go build -o nofx main.go

# 测试运行
./nofx
```

### 4.2 构建前端

```bash
cd ~/projects/nofx-dev/web

# 安装依赖
npm install
# 或使用 pnpm
pnpm install

# 构建生产版本
npm run build
# 或
pnpm build
```

### 4.3 配置 Supervisor（进程管理）

```bash
# 创建 Supervisor 配置
sudo nano /etc/supervisor/conf.d/nofx.conf
```

**nofx.conf 内容：**

```ini
[program:nofx-backend]
command=/home/nofx/projects/nofx-dev/nofx
directory=/home/nofx/projects/nofx-dev
user=nofx
autostart=true
autorestart=true
stderr_logfile=/home/nofx/projects/nofx-dev/logs/nofx.err.log
stdout_logfile=/home/nofx/projects/nofx-dev/logs/nofx.out.log
environment=JWT_SECRET="your-jwt-secret",CORS_ALLOWED_ORIGIN="https://yourdomain.com"
```

```bash
# 重新加载 Supervisor 配置
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start nofx-backend

# 查看状态
sudo supervisorctl status
```

### 4.4 配置 Nginx（反向代理）

```bash
# 创建 Nginx 配置
sudo nano /etc/nginx/sites-available/nofx
```

**Nginx 配置示例：**

```nginx
# 上游后端服务
upstream nofx_backend {
    server 127.0.0.1:8080;
}

# HTTP 服务器（重定向到 HTTPS）
server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    
    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

# HTTPS 服务器
server {
    listen 443 ssl http2;
    server_name yourdomain.com www.yourdomain.com;

    # SSL 证书配置（使用 Let's Encrypt）
    ssl_certificate /etc/letsencrypt/live/yourdomain.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/yourdomain.com/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;

    # 前端静态文件
    root /home/nofx/projects/nofx-dev/web/dist;
    index index.html;

    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api {
        proxy_pass http://nofx_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Referrer-Policy "no-referrer-when-downgrade" always;
}
```

```bash
# 启用站点
sudo ln -s /etc/nginx/sites-available/nofx /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
sudo systemctl enable nginx
```

### 4.5 配置 SSL 证书（Let's Encrypt）

```bash
# 安装 Certbot
sudo apt-get install -y certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

# 自动续期测试
sudo certbot renew --dry-run
```

### 4.6 配置防火墙

```bash
# 启用 UFW
sudo ufw enable

# 允许 SSH（重要！先执行这个）
sudo ufw allow 22/tcp

# 允许 HTTP 和 HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# 查看状态
sudo ufw status
```

```bash
sudo systemctl stop nginx     # 停止
```

### 5.3 健康检查脚本

创建健康检查脚本：

```bash
# 创建脚本
nano ~/projects/nofx-dev/scripts/health_check.sh
```

```bash
#!/bin/bash
# 健康检查脚本

API_URL="http://localhost:8080/api/health"
RESPONSE=$(curl -s -o /dev/null -w "%{http_code}" $API_URL)

if [ "$RESPONSE" != "200" ]; then
    echo "健康检查失败: HTTP $RESPONSE"
    # 发送告警（可以集成邮件、Slack 等）
    exit 1
else
    echo "服务健康: HTTP $RESPONSE"
    exit 0
fi
```

```bash
# 设置执行权限
chmod +x ~/projects/nofx-dev/scripts/health_check.sh

# 添加到 crontab（每5分钟检查一次）
crontab -e
# 添加：*/5 * * * * /home/nofx/projects/nofx-dev/scripts/health_check.sh
```

### 5.4 数据库备份

```bash
# 创建备份脚本
nano ~/projects/nofx-dev/scripts/backup_db.sh
```

```bash
#!/bin/bash
# 数据库备份脚本

BACKUP_DIR=~/projects/nofx-dev/backups
DB_PATH=~/projects/nofx-dev/data/config.db
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR

# 备份数据库
sqlite3 $DB_PATH ".backup $BACKUP_DIR/config_$DATE.db"

# 保留最近7天的备份
find $BACKUP_DIR -name "config_*.db" -mtime +7 -delete

echo "备份完成: config_$DATE.db"
```

```bash
# 设置执行权限
chmod +x ~/projects/nofx-dev/scripts/backup_db.sh

# 添加到 crontab（每天凌晨2点备份）
crontab -e
# 添加：0 2 * * * /home/nofx/projects/nofx-dev/scripts/backup_db.sh
```

## 故障排查

### 6.1 服务无法启动

**检查步骤：**

```bash

sudo lsof -i :8080
sudo lsof -i :3000

# 2. 检查进程状态
sudo supervisorctl status

# 3. 查看错误日志
tail -50 ~/projects/nofx-dev/logs/nofx.err.log

# 4. 手动测试运行
cd ~/projects/nofx-dev
./nofx
```

```bash

ls -lh ~/projects/nofx-dev/data/config.db

# 检查数据库完整性
sqlite3 ~/projects/nofx-dev/data/config.db "PRAGMA integrity_check;"

# 查看数据库大小
du -h ~/projects/nofx-dev/data/config.db
```

### 6.3 网络连接问题


## 安全加固

### 7.1 系统安全

```bash
# 1. 配置 Fail2ban（防止暴力破解）
sudo systemctl enable fail2ban
sudo systemctl start fail2ban

# 2. 禁用 root SSH 登录
sudo nano /etc/ssh/sshd_config
# 设置：PermitRootLogin no
sudo systemctl restart sshd

# 3. 配置 SSH 密钥认证
# 生成密钥对（在本地）
ssh-keygen -t rsa -b 4096

# 复制公钥到服务器
ssh-copy-id nofx@your-server-ip
```

### 7.2 应用安全

```bash
# 1. 设置文件权限
chmod 600 ~/projects/nofx-dev/.env
chmod 600 ~/projects/nofx-dev/config.json
chmod 755 ~/projects/nofx-dev/nofx

# 2. 定期更新依赖
cd ~/projects/nofx-dev
go get -u ./...
go mod tidy

cd ~/projects/nofx-dev/web
npm update
# 或
pnpm update
```
