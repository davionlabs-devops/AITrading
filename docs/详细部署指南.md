## 部署方式选择

### 🐳 Docker 部署（推荐）
- ✅ **优点**：最简单，自动处理所有依赖，一键启动
- ✅ **适合**：新手、快速部署、不想配置环境
- ⏱️ **时间**：10-15分钟

### 📦 手动部署
- ✅ **优点**：可以修改代码，更灵活
- ⚠️ **缺点**：需要手动安装所有依赖
- ⏱️ **时间**：30-60分钟

**建议：如果你是第一次部署，强烈推荐使用 Docker 方式！**

## 方式一：Docker 部署（推荐，最简单）

### 第一步：检查你的电脑

#### 1.1 检查操作系统

**Windows 用户：**
- 按 `Win + R`，输入 `winver`，查看 Windows 版本
- 需要 Windows 10 或更高版本
- **推荐使用 WSL2（Windows Subsystem for Linux）**，这样可以使用 Linux 命令
- 或者使用 PowerShell 或 CMD，但命令可能略有不同

**macOS 用户：**
- 点击左上角苹果图标 → 关于本机
- 需要 macOS 10.15 或更高版本

**Linux 用户：**
- 在终端输入：`cat /etc/os-release`
- 推荐 Ubuntu 20.04 或更高版本

#### 1.2 检查是否已安装 Docker

**Windows/macOS：**
1. 打开终端（Windows：PowerShell 或 CMD，macOS：终端）
2. 输入以下命令：
```bash
docker --version
```

**如果显示版本号**（如 `Docker version 24.0.0`），说明已安装，跳到第二步。

**如果显示 "command not found" 或 "找不到命令"**，需要安装 Docker：

**Windows 安装 Docker：**
1. 访问：https://www.docker.com/products/docker-desktop/
2. 下载 "Docker Desktop for Windows"
3. 双击安装包，按照提示安装
4. 安装完成后重启电脑
5. 打开 Docker Desktop 应用

**macOS 安装 Docker：**
1. 访问：https://www.docker.com/products/docker-desktop/
2. 下载 "Docker Desktop for Mac"（根据你的芯片选择 Intel 或 Apple Silicon）
3. 双击 `.dmg` 文件安装
4. 将 Docker 拖到 Applications 文件夹
5. 打开 Docker Desktop 应用

**Linux 安装 Docker：**
```bash
# Ubuntu/Debian
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 启动 Docker 服务
sudo systemctl start docker
sudo systemctl enable docker

# 将当前用户添加到 docker 组（可选，避免每次都用 sudo）
sudo usermod -aG docker $USER
# 重新登录后生效
```

### 第二步：准备项目文件

#### 2.1 下载项目

**方法 A：如果你有项目文件夹**
- 确保项目文件夹在：`/Users/ez/Downloads/ez1/nofx-dev`（macOS）或类似位置

**方法 B：从 Git 克隆（如果有 Git）**
```bash
# 打开终端，进入你想存放项目的目录
cd ~/Downloads  # macOS/Linux
# 或
cd C:\Users\你的用户名\Downloads  # Windows PowerShell

# 克隆项目（如果有 Git 仓库地址）
git clone <你的仓库地址> nofx-dev
cd nofx-dev
```

**Windows 用户注意：**
- 如果使用 PowerShell，路径使用反斜杠：`cd C:\Users\你的用户名\Downloads`
- 如果使用 WSL2，路径使用正斜杠：`cd /mnt/c/Users/你的用户名/Downloads`

#### 2.2 进入项目目录

**macOS/Linux：**
```bash
cd /Users/ez/Downloads/ez1/nofx-dev
```

**Windows PowerShell：**
```powershell
cd C:\Users\ez\Downloads\ez1\nofx-dev
# 或使用你的实际路径
```

**Windows WSL2：**
```bash
cd /mnt/c/Users/ez/Downloads/ez1/nofx-dev
# 或使用你的实际路径
```

**验证是否在正确目录：**
```bash
# macOS/Linux/WSL2：查看当前目录
pwd

# Windows PowerShell：查看当前目录
Get-Location

# 查看目录内容（应该看到 config.json.example, docker-compose.yml 等文件）
# macOS/Linux/WSL2
ls -la

# Windows PowerShell
dir
# 或
ls
```

### 第三步：创建配置文件

#### 3.1 复制配置文件模板

在终端输入：
```bash
cp config.json.example config.json
```

**验证文件已创建：**
```bash
ls -la config.json
```

应该看到 `config.json` 文件。

#### 3.2 创建环境变量文件（可选）

如果需要自定义端口等设置，可以创建 `.env` 文件：

```bash
# 创建 .env 文件
cat > .env << EOF
# 前端端口（默认 3000）
NOFX_FRONTEND_PORT=3000

# 后端端口（默认 8080）
NOFX_BACKEND_PORT=8080

# 时区设置（默认 Asia/Shanghai）
NOFX_TIMEZONE=Asia/Shanghai
EOF
```

**如果不创建 .env 文件，系统会使用默认值。**

#### 3.3 编辑配置文件（可选）

**如果你使用默认配置，可以跳过这一步。**

如果需要修改配置，使用文本编辑器打开 `config.json`：

**macOS/Linux：**
```bash
nano config.json
# 或
vim config.json
# 或直接用你喜欢的编辑器打开
```

**Windows：**
```bash
notepad config.json
```

**配置文件说明：**
```json
{
  "admin_mode": true,              // true = 无需登录，false = 需要登录
  "api_server_port": 8080,         // 后端端口（一般不用改）
  "use_default_coins": true,       // true = 使用默认币种列表
  "leverage": {
    "btc_eth_leverage": 5,         // BTC/ETH 最大杠杆
    "altcoin_leverage": 5          // 其他币种最大杠杆
  }
}
```

**保存文件：**
- nano：按 `Ctrl + X`，然后按 `Y`，再按 `Enter`
- vim：按 `Esc`，输入 `:wq`，按 `Enter`
- 其他编辑器：直接保存

### 第四步：启动服务

#### 4.1 使用启动脚本（最简单）

**给脚本添加执行权限：**
```bash
chmod +x start.sh
```

**启动服务：**
```bash
./start.sh start --build
```

**这个命令会：**
1. 检查 Docker 是否安装
2. 检查配置文件是否存在
3. 构建 Docker 镜像（第一次需要下载，可能需要 5-10 分钟）
4. 启动后端和前端服务

**等待看到以下信息：**
```
[SUCCESS] 服务已启动！
[INFO] Web 界面: http://localhost:3000
[INFO] API 端点: http://localhost:8080
```

#### 4.2 或者使用 Docker Compose 直接启动

```bash
docker compose up -d --build
```

**参数说明：**
- `up`：启动服务
- `-d`：后台运行
- `--build`：重新构建镜像

### 第五步：验证服务是否启动

#### 5.1 检查容器状态

```bash
docker ps
```

**应该看到两个容器在运行：**
- `nofx-trading`（后端）
- `nofx-frontend`（前端）

**如果容器没有运行，查看日志：**
```bash
docker compose logs
```

#### 5.2 测试后端 API

```bash
curl http://localhost:8080/api/health
```

**应该返回：**
```json
{"status":"ok","time":null}
```

#### 5.3 打开 Web 界面

1. 打开浏览器（Chrome、Firefox、Safari 等）
2. 访问：**http://localhost:3000**
3. 应该看到登录页面或主界面

**如果看不到页面：**
- 检查端口 3000 是否被占用
- 查看前端日志：`docker compose logs nofx-frontend`

### 第六步：管理服务

#### 6.1 查看日志

```bash
# 查看所有服务日志
./start.sh logs

# 或使用 Docker Compose
docker compose logs -f

# 只看后端日志
docker compose logs -f nofx

# 只看前端日志
docker compose logs -f nofx-frontend
```

#### 6.2 停止服务

```bash
./start.sh stop
# 或
docker compose stop
```

#### 6.3 重启服务

```bash
./start.sh restart
# 或
docker compose restart
```

#### 6.4 查看服务状态

```bash
./start.sh status
# 或
docker compose ps
```

## 方式二：手动部署（适合开发者）

### 第一步：安装 Go 语言

#### 1.1 macOS 安装 Go

**使用 Homebrew（推荐）：**
```bash
# 如果没有 Homebrew，先安装
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装 Go
brew install go

# 验证安装
go version
```

**手动安装：**
1. 访问：https://go.dev/dl/
2. 下载 macOS 版本（.pkg 文件）
3. 双击安装
4. 打开终端验证：`go version`

#### 1.2 Linux 安装 Go

```bash
# 下载 Go（版本 1.21 或更高）
cd /tmp
wget https://go.dev/dl/go1.21.5.linux-amd64.tar.gz

# 解压到 /usr/local
sudo tar -C /usr/local -xzf go1.21.5.linux-amd64.tar.gz

# 设置环境变量
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
echo 'export GOPATH=$HOME/go' >> ~/.bashrc
source ~/.bashrc

# 验证安装
go version
```

#### 1.3 Windows 安装 Go

1. 访问：https://go.dev/dl/
2. 下载 Windows 版本（.msi 文件）
3. 双击安装，按照提示完成
4. 打开 PowerShell 验证：`go version`

### 第二步：安装 Node.js

#### 2.1 macOS 安装 Node.js

**使用 Homebrew：**
```bash
brew install node
```

**或下载安装包：**
1. 访问：https://nodejs.org/
2. 下载 LTS 版本（.pkg 文件）
3. 双击安装

#### 2.2 Linux 安装 Node.js

```bash
# 使用 NodeSource 仓库
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证安装
node --version
npm --version
```

#### 2.3 Windows 安装 Node.js

1. 访问：https://nodejs.org/
2. 下载 LTS 版本（.msi 文件）
3. 双击安装
4. 打开 PowerShell 验证：`node --version`

### 第三步：安装 TA-Lib（技术分析库）

#### 3.1 macOS 安装 TA-Lib

```bash
brew install ta-lib
```

#### 3.2 Linux 安装 TA-Lib

```bash
# 安装依赖
sudo apt-get install -y build-essential wget

# 下载 TA-Lib
cd /tmp
wget http://prdownloads.sourceforge.net/ta-lib/ta-lib-0.4.0-src.tar.gz
tar -xzf ta-lib-0.4.0-src.tar.gz
cd ta-lib/

# 编译安装
./configure --prefix=/usr
make
sudo make install

# 更新库路径
sudo ldconfig
```

#### 3.3 Windows 安装 TA-Lib

**比较复杂，建议使用 Docker 部署或 WSL2**

#### 4.1 安装后端依赖

## 部署后配置

### 第一步：访问 Web 界面

1. 打开浏览器
2. 访问：**http://localhost:3000**

### 第二步：配置 AI 模型

1. 点击页面上的 **"AI模型配置"** 按钮
2. 选择要使用的 AI 模型（DeepSeek 或 Qwen）
3. 输入你的 API Key：
   - **DeepSeek API Key**：从 https://platform.deepseek.com 获取
   - **Qwen API Key**：从 https://dashscope.console.aliyun.com 获取
4. 点击 **"保存"**

### 第三步：配置交易所

1. 点击 **"交易所配置"** 按钮
2. 选择要使用的交易所（Binance、Hyperliquid 或 Aster DEX）
3. 输入 API 凭证：

   **Binance：**
   - API Key
   - Secret Key

   **Hyperliquid：**
   - Private Key（去掉 0x 前缀）
   - Wallet Address

   **Aster DEX：**
   - User Address
   - Signer Address
   - Private Key（去掉 0x 前缀）

4. 点击 **"保存"**

### 第四步：创建交易员

1. 点击 **"创建交易员"** 按钮
2. 填写信息：
   - **交易员名称**：给你的交易员起个名字
   - **AI 模型**：选择已配置的 AI 模型
   - **交易所**：选择已配置的交易所
   - **初始资金**：设置初始余额（用于计算收益率）
   - **扫描间隔**：建议 3-5 分钟
   - **系统提示词模板**：选择策略（如 "APEX 前端自研策略"）
3. 点击 **"创建"**

### 第五步：启动交易

1. 在交易员列表中，找到你刚创建的交易员
2. 点击 **"启动"** 按钮
3. 交易员开始运行，AI 会每 3-5 分钟分析市场并做出决策

## 常见问题解决

### 问题 1：Docker 命令找不到

**解决方案：**
- Windows/macOS：确保 Docker Desktop 已启动
- Linux：检查 Docker 是否安装：`which docker`
- 如果未安装，参考第一步的安装说明

### 问题 2：端口被占用

**错误信息：**
```
Error: port 8080 is already in use
```

**解决方案：**
```bash
# 查看占用端口的进程
# macOS/Linux
lsof -i:8080
# 或
netstat -an | grep 8080

# 停止占用端口的进程
kill -9 <进程ID>

# 或修改配置文件中的端口
# 编辑 config.json，修改 api_server_port
```

### 问题 3：前端无法连接后端

**检查：**
1. 后端是否运行：`curl http://localhost:8080/api/health`
2. 检查浏览器控制台错误（F12）
3. 检查防火墙设置

### 问题 4：Docker 构建失败

**解决方案：**
```bash
# 清理旧的镜像和容器
docker compose down
docker system prune -a

# 重新构建
docker compose up -d --build
```

### 问题 5：TA-Lib 找不到（手动部署）

**macOS：**
```bash
brew install ta-lib
```

**Linux：**
```bash
# 参考第三步的安装说明
sudo ldconfig  # 更新库路径
```

### 问题 6：数据库错误

**解决方案：**
```bash
# 删除旧数据库（会丢失数据！）
rm config.db

# 重新启动，系统会自动创建新数据库
./start.sh restart
```

### 问题 7：前端页面空白

**检查：**
1. 查看浏览器控制台（F12）是否有错误
2. 检查前端服务是否运行：`curl http://localhost:3000`
3. 清除浏览器缓存，强制刷新（Ctrl+F5 或 Cmd+Shift+R）

## 服务器部署（生产环境）

### 第一步：准备服务器

#### 1.1 购买服务器

推荐云服务商：
- 阿里云
- 腾讯云
- AWS
- DigitalOcean

**推荐配置：**
- CPU: 2-4 核心
- 内存: 4-8GB
- 磁盘: 50GB+ SSD
- 带宽: 5Mbps+

#### 1.2 连接服务器

**使用 SSH：**
```bash
ssh root@你的服务器IP
# 或
ssh 用户名@你的服务器IP
```

**Windows 用户可以使用：**
- PuTTY
- Windows Terminal
- WSL2

### 第二步：在服务器上安装 Docker

参考 [方式一：Docker 部署](#方式一docker-部署推荐最简单) 中的 Docker 安装步骤。

### 第三步：上传项目文件

#### 方法 A：使用 Git（推荐）

```bash
# 在服务器上
cd /opt  # 或你喜欢的目录
git clone <你的仓库地址> nofx-dev
cd nofx-dev
```

#### 方法 B：使用 SCP 上传

**在本地电脑：**
```bash
# macOS/Linux
scp -r /Users/ez/Downloads/ez1/nofx-dev root@服务器IP:/opt/

# Windows (使用 PowerShell 或 WSL)
scp -r C:\path\to\nofx-dev root@服务器IP:/opt/
```

### 第四步：配置服务器

#### 4.1 创建配置文件

```bash
cd /opt/nofx-dev
cp config.json.example config.json
nano config.json  # 编辑配置
```

#### 4.2 配置防火墙

```bash
# Ubuntu/Debian
sudo ufw allow 3000/tcp  # 前端端口
sudo ufw allow 8080/tcp  # 后端端口（如果要从外部访问）
sudo ufw enable
```

### 第五步：启动服务

```bash
cd /opt/nofx-dev
chmod +x start.sh
./start.sh start --build
```

### 第六步：配置域名和 HTTPS（可选）

#### 6.1 安装 Nginx

```bash
sudo apt-get install nginx
```

#### 6.2 配置 Nginx 反向代理

创建配置文件：
```bash
sudo nano /etc/nginx/sites-available/nofx
```

添加以下内容：
```nginx
server {
    listen 80;
    server_name 你的域名.com;  # 替换为你的域名

    # 前端
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # 后端 API
    location /api {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用配置：
```bash
sudo ln -s /etc/nginx/sites-available/nofx /etc/nginx/sites-enabled/
sudo nginx -t  # 测试配置
sudo systemctl reload nginx
```

#### 6.3 配置 SSL 证书（使用 Let's Encrypt）

```bash
# 安装 Certbot
sudo apt-get install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d 你的域名.com

# 证书会自动续期
```

### 第七步：设置自动启动

#### 7.1 使用 systemd（推荐）

创建服务文件：
```bash
sudo nano /etc/systemd/system/nofx.service
```

添加内容：
```ini
[Unit]
Description=APEX AI Trading System
After=docker.service
Requires=docker.service

[Service]
Type=oneshot
RemainAfterExit=yes
WorkingDirectory=/opt/nofx-dev
ExecStart=/usr/bin/docker compose up -d
ExecStop=/usr/bin/docker compose down
User=root

[Install]
WantedBy=multi-user.target
```

启用服务：
```bash
sudo systemctl daemon-reload
sudo systemctl enable nofx
sudo systemctl start nofx
```

#### 8.2 定期备份

```bash
# 创建备份脚本
nano /opt/nofx-dev/backup.sh
```

添加内容：
```bash
#!/bin/bash
BACKUP_DIR="/opt/backups/nofx"
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR
cp /opt/nofx-dev/config.db $BACKUP_DIR/config.db.$DATE
cp /opt/nofx-dev/config.json $BACKUP_DIR/config.json.$DATE

# 保留最近 7 天的备份
find $BACKUP_DIR -name "*.db.*" -mtime +7 -delete
find $BACKUP_DIR -name "*.json.*" -mtime +7 -delete
```

设置定时任务：

```bash
0 2 * * * /opt/nofx-dev/backup.sh
```
